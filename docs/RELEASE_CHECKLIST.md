# Release Checklist

Before making the repository public:

- [ ] Replace `YOUR-USERNAME` in `CITATION.cff`.
- [ ] Add the final `.exe` or prepare a GitHub Release.
- [ ] Confirm the application imports CIF files successfully.
- [ ] Test at least 3–5 CIF files on a clean Windows computer.
- [ ] Add a screenshot of the final interface.
- [ ] Confirm the displayed model metrics match the manuscript.
- [ ] Confirm no private paths, API keys, usernames, or confidential files are bundled.
- [ ] Create release tag `v1.0.0`.
- [ ] Put the final GitHub URL into the manuscript only after the repository is public.
- [ ] Optionally archive the release on Zenodo to obtain a permanent DOI.
