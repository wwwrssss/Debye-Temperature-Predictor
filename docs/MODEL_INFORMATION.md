# Model Information

## Target property

Debye temperature, Θ_D, reported in kelvin.

## Model performance reported in the manuscript

Five-fold cross-validation:

- R² = 0.968
- MAE = 28.12 K
- RMSE = 43.64 K

## Intended use

Rapid screening of inorganic crystalline materials.

## Important limitation

The application provides machine-learning predictions and should be treated as a screening tool. Experimental measurements and first-principles calculations remain necessary where high-accuracy property determination is required.

## Model disclosure

This public repository distributes the compiled standalone application. The source code is not distributed in this repository.
