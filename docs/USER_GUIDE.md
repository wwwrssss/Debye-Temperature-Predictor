# User Guide

## Step 1 — Download

Go to the repository's **Releases** page and download:

`Debye_Temperature_Predictor.exe`

## Step 2 — Start the application

Double-click the executable.

Windows may display a security warning for unsigned research software. Check that the file was downloaded from the official repository before running it.

## Step 3 — Import a CIF

Choose a crystallographic information file (`.cif`).

## Step 4 — Predict

Run the prediction and record the Debye temperature shown by the software.

## Step 5 — Report software version

For publication-quality reproducibility, record the software release version, for example:

`Debye Temperature Predictor v1.0.0`
